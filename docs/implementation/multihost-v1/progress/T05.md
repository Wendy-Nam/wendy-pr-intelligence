- Host mode can retrieve the exact persisted pending request through `jobs` CLI; request payload is not lost after process restart.
- Bounded `repair` CLI replaces only pending/failed job request hash/payload and refuses succeeded or unknown jobs.
- Engine `reject_result()` records failed immutable attempts and updates only the target job for safe retry/resume.
